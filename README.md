# English–Vietnamese Commercial Translation Evaluation

This repository documents a pilot research project on English–Vietnamese translation quality in commercial and everyday communication contexts.

The project examines whether translated Vietnamese texts are not only fluent, but also accurate, natural, terminologically appropriate, and suitable for Vietnamese readers.

* bilingual evaluation rubric
* human evaluation guidelines
* anonymized rating results
* qualitative error analysis

## Research Focus

The project is designed to explore English–Vietnamese translation quality beyond surface-level fluency. It focuses on meaning accuracy, terminology, naturalness, tone, localization, and the risk of misleading translation.
